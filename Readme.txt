Python Játékfelület (Pygame)

Koncepció: A papírra rajzolt vázlat egy 2D-s akciójáték főmenüjét,
HUD-ját (életerősáv, fegyver ikonok) vagy egy inventory elrendezését ábrázolja.

Kimenet: A felismert dobozokból és feliratokból a rendszer futtatható Python kódot generál,
felépítve a Pygame osztályokat,
a megfelelő Rect objektumokat és a képernyőre rajzoló (blit, draw.rect) függvényeket,
amit egyből be lehet emelni egy játékmotor fő ciklusába.
